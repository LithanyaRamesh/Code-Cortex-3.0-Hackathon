🔒 Privacy Mode & Secure Sandbox Architecture

How MailShield AI securely handles your email data with zero data leakage.

In-Memory NLP Execution

Email content is tokenized and transformed into TF-IDF vector matrices strictly in volatile RAM. Raw message payloads are never exposed to external LLMs.

Non-Executable Sandbox

Attachments, hyperlinks, and RFC 822 source code are parsed safely using deterministic AST parsers without executing scripts.

Local Storage & Purge

Scans are stored securely in your isolated local SQLite database. You retain 100% control to purge all historical data at any time.

Data Retention Control

Permanently delete all stored scan history and reset telemetry.
